# Portfólio — Luiz Otávio

[Acessar o portfólio](https://luizott.github.io/Meu-Portifolio/)

Analista de MarTech e IA, bacharel em Administração pela UFV e técnico em Informática. O portfólio reúne projetos de desenvolvimento web, automação, dados e inteligência comercial.

- **Rotom Soluções:** site institucional público.
- **Dashboard de marketing:** prévia reconstruída com dados fictícios.
- **Prospecção B2B:** ferramenta de pesquisa de mercado e organização de contatos.
- **Gestão de eventos:** prévia reconstruída com dados fictícios.

O site é publicado pelo GitHub Pages a partir de `docs/`, sem etapa de build. Os textos dos projetos e a lista de ferramentas estão em `docs/content.js`. As imagens do site ficam em `docs/assets/`. Para conferir localmente, sirva a pasta `docs/` por HTTP para que o navegador possa carregar os SVGs locais.

A documentação dos projetos em desenvolvimento continua em [projects/](projects/README.md).
